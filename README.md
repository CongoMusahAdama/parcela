# Parcela

Bus parcel pre-booking and tracking platform — mobile-first web app.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current scope

- **Phase 0:** Next.js, Tailwind, design tokens, shared UI
- **Phase 1 (Sender):** Home, station finder, parcel form, booking confirmation

## Tech stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

## Typography

- **Poppins** (`font-display`) — headings, buttons, badges, UI emphasis (500 / 600 / 700)
- **Inter** (`font-body`) — paragraphs, inputs, labels, helper text (400 / 500)

See `src/lib/typography.ts` and `src/app/globals.css`.

## Public theme

- Primary: Teal `#0D9488`
- Accent: Amber `#F59E0B`
